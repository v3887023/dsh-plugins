# dsh-noir-skin

近黑石墨 + 香槟金的 DSH 换肤插件。纯 token 层实现：一层
`ctx.theme.overrideTokens` 覆盖掉 shell 的 alias 变量，不动任何宿主样式表，
停用后完全回到 DSH 内建配色。

## 它改了什么

- **背景四阶**：`bg-base #0E0E10` → `layer-1 #18181B` → `layer-2 #202024` →
  `layer-3 #28282D`，替代原本几乎分不出来的三档灰。
- **发丝线**：`border-l1/l2/l3/l4` 提到 7% / 11% / 16% / 20%，暗色下分区看得见。
- **墨色**：主文字 `#F2EFE9` 暖白、次要 `#A19C93`、三级 `#7A756D`，不用纯白。
- **强调色**：焦点环、链接、选中态、轨迹高亮共用一组 token，三档可切
  （香槟金 / 铜橙 / 冷青），浅深两套各自给值。
- **组件面**：卡片、气泡、代码块、菜单浮层、滚动条、输入框都跟同一套 ramp。
- **状态色**：成功 / 警告 / 错误各降一档饱和度，信号仍在但不抢眼。

## 在哪用

**右侧栏的一个标签页**（`ctx.sidebarRightTabs` 注册的 tab 类型，body 挂在
`sidebar.right.pane.tab`）：

- 打开右侧栏，在 guide 页里点「墨金外观」卡片；或者 设置 → 外观 → 墨金外观 →
  「在右侧栏打开」。
- 页里是三个强调色块 + 四个实时滑块（画布深度、层次强度、金色亮度、发丝线）
  + 恢复默认 + 启用开关。
- 它跟「文件」「终端」「设计台」是同一类页面，可以拖进分栏、也能浮动。

表面色是按 HSL 现算的，不是四套预设，滑块能停在任意中间值。

## 会话排版

设置页里另有一组「会话排版」，五选一，**与配色开关互不影响**（可以只开排版不开配色）：

| 预设 | 行高 | 块距 | 列宽 | 附加 |
|---|---|---|---|---|
| 不改 | — | — | — | DSH 默认 |
| 紧凑 | 1.63 | 16 | 748 | 显式声明原值，作为基准 |
| 阅读 | 1.75 | 22 | 700 | 表格内边距 9/12 |
| 结构 | 1.88 | 28 | 660 | h2 下划细线、序号金圆徽标、引用卡片、表格斑马纹 |
| 文档 | 2.0 | 34 | 620 | 上列全部 + h2 26px、代码块圆角 12 |

实现方式：列宽走 `--dsh-chat-user-width` 这个变量口；行高与块距落在宿主 CSS
module 的 `_root` / `_body` 类上，按类名前缀匹配、限定在
`[data-slot="conversation.chat.node"]` 作用域内，且全部以
`body[data-noir-type="…"]` 开头——不选预设时零影响；DSH 升级若改了类名，规则
失配后自动退回原排版，不会把界面弄坏。

偏好存在浏览器 `localStorage`（`dsh.noir-skin.enabled`、`.accent`、`.tuning`、
`.type`），不写 profile。

## 边界

- 只覆盖 alias / specific 层；`--dsw-static-*` 色板不动，DSH 的派生逻辑照常。
- 不接管布局、不改宿主类名、不替换任何 slot 内容，只在设置页注册一个分节。
- DSH 的浅色 / 深色 / 跟随系统仍由内建「外观」决定，本插件两套配色都给了。
- 与其它主题插件同时启用时，后注册的 `overrideTokens` 层胜出（同值同源者覆盖）。
